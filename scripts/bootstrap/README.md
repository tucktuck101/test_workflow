# Bootstrap Scripts

This directory contains both preserved historical Codex bootstrap utilities and the active GitHub presentation-repo setup helpers.

Active helpers:

- `create_presentation_repo.sh`: creates the clean `battleships-rl-platform` import.
- `setup_github_repo.sh`: creates labels, environments, Project metadata, and repo variables.

Use the active commands in `Makefile`, `README.md`, and `AGENTS.md` for day-to-day development and demo work.
